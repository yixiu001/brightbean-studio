# Chinese Internationalization Follow-up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Translate the remaining English labels reported on workspace settings, notifications, and publish pages while preserving stored values and timezone identifiers.

**Architecture:** Use Django's existing gettext pipeline for template and model-choice labels. Introduce a presentation-only timezone-label template filter so option values remain valid IANA identifiers while visible text is localized.

**Tech Stack:** Django 5.1 templates, `gettext_lazy`, custom template filters, pytest-django, gettext PO/MO catalogs.

## Global Constraints

- Do not rewrite user-entered data or existing database rows.
- Keep notification choice values such as `post_submitted` unchanged.
- Keep timezone option values such as `Asia/Shanghai` unchanged.
- Preserve English-mode labels.
- Do not broaden the change beyond the three reported surfaces.
